## Sobre

Sou desenvolvedor de software com experiência prática no desenvolvimento, manutenção e evolução de sistemas web em ambiente de produção.

Atuei no desenvolvimento de aplicações **end-to-end**, desde o levantamento de necessidades com stakeholders e implementação das funcionalidades até testes, deploy e manutenção.

Tenho maior foco em **Back-end Java**, utilizando principalmente **Java, Spring Boot, Spring Security, JPA/Hibernate, APIs REST e PostgreSQL**, além de experiência com **Docker, CI/CD, Redis e Linux**.

Também possuo experiência na investigação de problemas, correção de bugs, validação de funcionalidades e transformação de processos manuais em soluções de software.
